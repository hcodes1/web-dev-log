Exploring Hyperlinks in HTML

Hyperlinks (`` tags) are fundamental to the web, connecting different pages and resources.

External Links

External links take you to websites outside of the current domain. It's good practice to open these in a new tab.

  • Visit Google (opens in a new tab).
    `target="_blank"` opens the link in a new browser tab.
    `rel="noopener noreferrer"` is a security measure recommended when using `target="_blank"`.
  • Learn more on Wikipedia's Hyperlink page.

Internal Links

Internal links take you to other pages within the same website.

  • Go to our About Us page.
  • Visit the Products section.
  • Access the Contact Us page.

(Remember: For these to work, `about.html`, `products.html`, and `contact.html` must be in the same folder.)

Internal Anchor Links (Same Page Navigation)

Anchor links allow you to jump to specific sections within the *current* page. Click these links and observe how the page scrolls to the corresponding section.

Section 1: What is HTML?

HTML (HyperText Markup Language) is the standard markup language for documents designed to be displayed in a web browser. It can be assisted by technologies such as Cascading Style Sheets (CSS) and scripting languages such as JavaScript. Web browsers receive HTML documents from a web server or from local storage and render the documents into multimedia web pages. HTML describes the structure of a web page semantically and originally included cues for the appearance of the document.

Section 2: Types of Links

As demonstrated on this page, there are primarily three types of links commonly used:

  1. **External Links:** Point to resources on different websites.
  2. **Internal Links:** Point to different pages within the same website.
  3. **Anchor Links (or Fragment Identifiers):** Point to a specific location (an element with an `id`) within the same document or another document.

Section 3: Best Practices

When creating links, consider the following best practices:

  • Use descriptive link text that clearly indicates the destination.
  • Ensure `target="_blank"` is accompanied by `rel="noopener noreferrer"` for security.
  • Validate your link paths to avoid broken links.
